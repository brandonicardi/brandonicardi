### About

Technical consultant at **[Primary](https://primary.com.ar)** (part of **[A3 Mercados](https://a3mercados.com.ar)**), the tech company behind trading platforms and financial infrastructure for Argentina's capital markets. I'm on the critical response team (4-hour SLA), production issues, performance fixes, and bulk data operations on systems that can't afford downtime.

Day to day: SQL Server deep dives, stored procedure optimization, backend debugging, mass data scripts, API endpoint testing, and root cause analysis on problems that tend to show up at the worst possible time.

Finishing my **Systems degree** at UNLa. Outside of work, I build things for fun, from Windows internals experiments to web apps. I also game, which is why my dev machine has more CPU/GPU than it probably needs.
